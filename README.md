## Project Description
This project demonstrates RESTful API development using Java Spring Boot.

## Features
- Create Employee
- Get All Employees
- Update Employee
- Delete Employee

## Technologies Used
- Java
- Spring Boot
- Maven
- REST API

## API Endpoints

GET /api/employees  
POST /api/employees  
PUT /api/employees/{id}  
DELETE /api/employees/{id}

## How to Run
1. Clone the repository
2. Run `mvn spring-boot:run`
3. Access API at `http://localhost:8080/api/employees`
